# CorOS Desktop Dock Icons Directory
# Bu klasör CorOS masaüstü dock ikonları için ayrılmıştır.

## Desteklenen Format ve Boyutlar:
- **Format:** 32-bit veya 24-bit uncompressed `.bmp` (Bitmap) veya `.raw` RGBA
- **Tavsiye Edilen Çözünürlük:** 48x48 veya 64x64 piksel (veya 128x128 piksel kare)
- **Tasarım Stili:** macOS Squircle (kavisli köşeli kare)

## Dosya İsimleri:
1. `finder.bmp` -> Finder (Dosya Gezgini)
2. `terminal.bmp` -> Kali Cyber Terminal
3. `monitor.bmp` -> Sistem Monitörü & Telemetri
4. `cyber3d.bmp` -> CyberSpace 3D Motoru
5. `settings.bmp` -> Kişiselleştirme & Tema Ayarları
6. `trash.bmp` -> Çöp Kutusu / Depolama

*Not: Henüz bir ikon yüklemediğinizde CorOS çekirdeği otomatik olarak dahili ultra modern macOS squircle ikonlarını çizer.*
